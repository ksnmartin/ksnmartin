## Featured work

### [Online Bin Packing: Bounds, Certificates and Limits](https://github.com/ksnmartin/online-bin-packing-bounds)

A computational attack on the asymptotic competitive ratio of online bin packing, with the accompanying paper.

- Improved the verified upper bound of the Advanced Harmonic algorithm from 1.5782896 to 1.5782147, through a re-optimised proportion table and per-scenario optimal dual weights.
- Proved two theorems showing the 2018 lower-bound construction cannot be improved by adding new item batches, and closed the remaining window with machine certificates.
- Every number is exact rational arithmetic, and every claimed bound ships with a certificate that an independent checker re-verifies. Start at `docs/verification-guide.md` if you want to check rather than read.
